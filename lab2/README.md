### Индивидуальное задание (базовый уровень)

**Вариант 8**
**Общее задание:** Для фрагментов кода (выдаётся преподавателем) определить сложность каждого фрагмента и обосновать ответ. Реализовать шаблонную функцию, указанную в варианте.

```cpp
#include <iostream>
#include <stdexcept>

using namespace std;


template <typename T>
T findMin(T arr[], int n) {

    if (n <= 0) {
        throw invalid_argument("Массив пуст или размер некорректен");
    }


    T minElement = arr[0];


    for (int i = 1; i < n; ++i) {
        if (arr[i] < minElement) {
            minElement = arr[i];
        }
    }

    return minElement;
}

int main() {
    setlocale(LC_ALL, "ru");


    int intArr[] = {5, 2, 9, 1, 7};
    int n1 = sizeof(intArr) / sizeof(intArr[0]);
    cout << "Минимальный элемент (int): " << findMin(intArr, n1) << endl;


    double doubleArr[] = {3.14, 1.41, 2.71, 0.58};
    int n2 = sizeof(doubleArr) / sizeof(doubleArr[0]);
    cout << "Минимальный элемент (double): " << findMin(doubleArr, n2) << endl;

    char charArr[] = {'z', 'a', 'm', 'b'};
    int n3 = sizeof(charArr) / sizeof(charArr[0]);
    cout << "Минимальный элемент (char): " << findMin(charArr, n3) << endl;

    return 0;
}
```
Вывод:
```
Минимальный элемент (int): 1
Минимальный элемент (double): 0.58
Минимальный элемент (char): a
```

Контрольные вопросы

О-нотация (Big O) — это математическая запись, описывающая верхнюю границу роста времени выполнения или потребления памяти алгоритмом при увеличении размера входных данных. Нужна для абстрактной оценки эффективности алгоритмов независимо от мощности компьютера.

У доступа к элементу массива по индексу сложность O(1) (константная). Это происходит потому, что в памяти массив хранится непрерывно, и адрес нужного элемента вычисляется за одну математическую операцию (базовый адрес + индекс умножить на размер элемента).

У бинарного поиска сложность O(log n). На каждом шаге алгоритм отбрасывает половину оставшихся элементов, поэтому количество шагов равно логарифму по основанию 2 от количества элементов.

O(n log n) означает, что время работы растёт чуть быстрее, чем линейно, но медленнее, чем квадратично. Пример: эффективные алгоритмы сортировки, такие как быстрая сортировка (QuickSort) или сортировка слиянием (MergeSort).

Амортизированный анализ — это оценка среднего времени выполнения операции в худшем случае, учитывающая редкие «дорогие» операции, которые окупаются за счёт множества «дешёвых». Пример: добавление элемента в std::vector (вектор в C++). Обычно это O(1), но при переполнении выделяется новая память и копируются все элементы (O(n)). В среднем (амортизированно) это всё равно O(1).

У двух вложенных циклов по n итераций сложность O(n в квадрате) (квадратичная). Внешний цикл выполняется n раз, и для каждой его итерации внутренний цикл выполняется n раз (n умножить на n).

У рекурсивного вычисления чисел Фибоначчи (наивный метод) сложность O(2 в степени n) (экспоненциальная). Каждый вызов порождает два новых вызова, что создаёт огромное дерево повторных вычислений.

Шаблоны функций — это механизм C++, позволяющий писать одну функцию, которая работает с разными типами данных. Объявляются с помощью ключевого слова template перед функцией (например, template <typename T> T func(T a)), а используются как обычные функции — компилятор сам подставляет нужный тип.

Шаблоны классов — это «чертежи» для классов, которые могут работать с любыми типами. Объявляются также через template, а при использовании тип указывается в угловых скобках (например, vector<int> или MyClass<double>).

Преимущество шаблонов перед перегрузкой: шаблоны позволяют избежать дублирования кода. Вместо того чтобы писать 10 одинаковых функций для int, double, float и т.д., вы пишете один шаблон, и код становится более компактным и поддерживаемым.

Указать, что параметр — это тип, можно с помощью ключевого слова typename или class в угловых скобках: template <typename T> или template <class T> (разницы между ними в данном контексте нет).

Да, можно. Синтаксис: template <typename T1, typename T2, ...>. Например, функция, принимающая два аргумента разных типов: template <typename T, typename U> void print(T a, U b).

Измерение времени в C++ проводится с помощью библиотеки chrono (или ctime). Фиксируется время до начала работы алгоритма (auto start = high_resolution_clock::now();) и после (auto end = ...), затем вычисляется разница.

Многократное выполнение нужно, потому что современные компьютеры работают очень быстро. Для мелких алгоритмов время выполнения может составлять микросекунды, и погрешность системных часов будет слишком велика. Прогон в цикле (например, 1000 раз) сглаживает погрешность и даёт реальную картину.

Сложность важнее константы на больших данных. При малых объёмах данных алгоритм с плохой асимптотикой, но маленькой константой (например, O(n в квадрате) без накладных расходов) может работать быстрее, чем O(n log n) с огромной константой. Но при росте n алгоритм с лучшей сложностью всегда выиграет, так как рост функции нивелирует любые константы.
